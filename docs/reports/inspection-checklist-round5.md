# 점검표와 버그 확인 기록

2026-11-06. 새 기능보다 입력 정확성·원본 보존·복구 안전성을 우선합니다. 아래는 재현한 결함과 회귀 검증 항목입니다. 로컬 최종 검사 결과는 함께 기록하며, 호스팅 계정·외부 결제·법률 검토는 수행한 것으로 표시하지 않습니다.

## 우선 점검표

- [x] 금액·시간·사용량에 boolean/배열/객체/null이 숫자로 강제 변환되는지 재현
- [x] 존재하지 않는 날짜·윤년 경계가 정상 비용/청구서로 수용되는지 확인
- [x] 특수 이름·ID가 집계·통계·병합의 내부 객체와 충돌하는지 확인
- [x] 중복 ID를 가진 저장 데이터에서 한 건 삭제가 여러 건 삭제로 이어지는지 재현
- [x] 손상·중복 백업의 원본 보존과 복구 안내가 작동하는지 확인
- [x] 가림 규칙이 겹칠 때 지정한 원문의 일부가 남는지 재현
- [x] 민감정보 가림→복원이 원문과 정확히 일치하는지 확인
- [x] CR-only 개행의 사용자 지정 규칙과 사용 로그 파싱 확인
- [x] Codex 추론 토큰을 출력 토큰에 중복 합산하는지 공식 소스와 대조
- [ ] 실제 호스팅 계정에서 Lendnest Cloudflare 빌드 오류 로그 확인
- [ ] 실제 구매·환불·라이선스 제품별 제한을 결제 서비스 테스트 환경에서 검증
- [ ] 선택적 클라우드 백업의 사용자 간 접근 격리를 실제 설정에서 검증
- [ ] Safari·Firefox 및 실제 iOS/Android에서 백업·파일·클립보드 흐름 검증

## 발견한 버그와 수정

| 앱 | 재현한 결함 | 수정·회귀 검증 |
|---|---|---|
| QuickBill | 잘못된 타입의 비용 금액, 존재하지 않는 날짜 수용 | 숫자 타입·실제 달력 날짜 검증, 숫자 입력 문자열 유지 |
| Stampbook | 특수 pack/stamp ID의 복원 충돌, 특수 학생 이름의 통계 누락·크래시 | 프로토타입이 없는 사전, 실제 ID·이름 보존 테스트 |
| Stayline | 특수 장소 이름의 집계 누락·프로토타입 충돌 | 안전한 사전으로 장소별 합산·장소 수 보존 |
| Marginlog | 특수 태그·사건 ID로 조회·내보내기 결과가 누락 | 안전한 사전으로 원본 체인 변경 없이 조회 |
| Lendnest | boolean/배열/객체가 대여금·상환금으로 변환 | 숫자 타입 검사 및 정상 숫자 문자열 회귀 |
| Quotanest | 잘못된 타입의 사용량, CR 개행 로그 누락, Codex 추론 토큰 이중 합산 | 파싱 타입·개행 보완, 공식 TokenUsage 계산과 대조 |
| Shadepad | CR 규칙 누락, 사용자 지정 규칙과 내장 규칙의 겹침으로 가림 일부 누락 | 개행 지원, 겹치는 범위의 합집합을 가리고 정확 복원 |
| QuoteFit(App8) | 손상 저장 데이터의 중복 ID에서 다른 기록까지 함께 삭제 | 원본 행을 유지하며 충돌 ID 복구, 실제 한 건 삭제 테스트 |
| RenewLedger(App9) | 배열 등의 예산 값이 숫자로 변환 | 백업 예산 타입 검사 |
| PromptVault(App10) | 중복 ID 백업이 정상으로 처리되어 편집·삭제 대상 모호 | 중복을 invalid로 보고, 기존 원본 보호와 복구 흐름 테스트 |

## 중요도

- **데이터 손실 위험:** QuoteFit의 중복 ID는 손상 데이터에서 한 건 삭제 시 다른 행이 함께 삭제될 수 있는 조건부 결함입니다. 현재 데이터 형식은 유지하고 충돌을 해소합니다.
- **민감정보 가림 누락:** Shadepad의 사용자 지정 구문이 내장 탐지와 겹치면 일부 텍스트가 남을 수 있었습니다. 겹침 전체를 가리도록 수정했으며, 실제 외부 정보 유출이 관측된 것은 아닙니다. 규칙 기반 도구이므로 모든 민감정보 탐지를 보장하지 않습니다.
- **집계·복원 정확성:** 나머지 확인 사례는 잘못된 값 수용, 누락·오집계·화면 오류입니다. 특수 이름의 메모리 내 프로토타입 충돌은 수정했으며 임의 코드 실행은 재현하지 않았습니다.

## 재발 방지

가져오기 오류를 조용히 정상 데이터로 바꾸지 않기, 사용자 입력 이름·ID에 일반 객체를 사전처럼 쓰지 않기, 원문과 백업 형식 보존, 수정 사례의 단위·실제 브라우저 회귀를 유지합니다. 외부 서비스 검증과 브라우저별 실제 기기 검증은 위 미완료 항목으로 남깁니다. 이 점검은 전면 보안 감사나 무결함 보증이 아닙니다.

## 후속 점검

Firefox·WebKit 자동 검사와 클라우드 코드 추가 점검은 [미확인 항목 후속 점검](external-verification.md)에 기록했습니다. 실제 구매·환불·계정 간 격리·실물 기기 검증은 사용자께서 추후 직접 진행하는 범위로 유지합니다.
