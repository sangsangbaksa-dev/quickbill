# 텍스트 처리 및 사용성 개선

사용자가 제보한 Quotanest의 `하하하` 미제거 문제를 중심으로 텍스트 처리 경계 사례를 수정했습니다. 언어모델을 호출하는 의미 요약이 아니라 브라우저 안에서 실행하는 규칙 기반 정리입니다. 모든 군더더기 표현을 자동으로 판별한다고 보장하지 않습니다.

- Quotanest: 일반 문장의 독립된 웃음 표현을 제거하고 인용·코드·단어 내부의 텍스트는 보존합니다. 코드 블록의 시작/종료 구분도 보완합니다.
- QuickBill·Stampbook: 화면상 같은 한글의 유니코드 조합 방식이 달라도 검색되도록 비교를 정규화합니다. 저장된 원문은 변경하지 않습니다. 목록 정렬과 검색 결과 확인·초기화 기능을 개선합니다.
- Stayline: 텍스트·CSV·달력의 줄바꿈과 날짜 처리 사례를 보완합니다. 같은 날 끝나는 달력 일정을 진행 중 여행으로 잘못 가져오는 문제를 수정합니다.
- Marginlog: 기록의 날짜 범위 검색과 결과 확인·내보내기 흐름을 개선합니다.
- Lendnest: 기한 범위 필터와 검색 결과 확인·초기화·CSV 내보내기를 추가합니다.
- Shadepad: 명시적 비밀번호 대입의 짧은 값과 구분자 없는 국내 휴대전화 번호의 탐지 누락을 보완합니다. 규칙이 놓치는 정보가 있을 수 있으므로 사용자는 가림 결과를 검토해야 합니다.
- App8: 한글 검색, CSV 구조 오류 처리와 BOM이 있는 백업 가져오기를 보완합니다.
- App9: BOM이 있는 JSON 백업 인식을 보완합니다.
- App10: 한글 변수 이름의 조합 방식, CR 줄바꿈과 특수 이름의 기본값 처리를 보완합니다.

기존 데이터와 백업 형식을 유지합니다. 직접 배포 명령을 실행하지 않으며, GitHub에 연결된 호스팅의 자동 빌드·배포는 저장소 변경으로 시작될 수 있습니다. 각 저장소의 테스트는 회귀 사례와 실제 브라우저 흐름으로 검증합니다.
